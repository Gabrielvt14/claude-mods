# claude-mods

Personal marketplace of Claude Code mods.

## Install

```
/plugin marketplace add gabrielvt14/claude-mods
/plugin install rgb-statusline@gabrielvt14-mods
```

Start a new session after installing.

## Update

1. Edit the mod under `mods/<name>/`.
2. Bump `version` in `mods/<name>/.claude-plugin/plugin.json` and in `.claude-plugin/marketplace.json`.
3. Commit and push.
4. On the other machine: `/plugin update rgb-statusline@gabrielvt14-mods`.

## Mods

| mod | what it does |
|---|---|
| `rgb-statusline` | Truecolor status line: repo, branch, gradient context bar, cost, lines changed, model, and 5-hour session usage with reset countdown |

## Adding a mod

Create `mods/<name>/` with a `.claude-plugin/plugin.json` and add an entry to
`.claude-plugin/marketplace.json`.

`mods/*/.claude-plugin/types/` is generated by Claude Code each time it loads a mod and is not
committed.
